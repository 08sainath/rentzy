# RENTZY

**Find Your Space. Feel at Home.**

RENTZY is a rental discovery platform concept for PGs, co-living spaces, apartments and independent houses.

## Current phase: Frontend

The initial responsive homepage includes:
- RENTZY brand header and hero section
- Search by city / neighbourhood
- Property category and monthly budget filters
- Property cards with amenities, pricing and save controls
- Owner listing call-to-action
- Responsive desktop and mobile layouts

> The current property cards are sample demonstration data. Authentication, real listings, enquiry workflows, payments and owner/admin dashboards are not connected yet.

## Tech stack
- Next.js 15 (App Router)
- React 19
- TypeScript
- Tailwind CSS 4
- Lucide React icons

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.
